# AD350_PATS
AD350_PATS — Propulsion Assembly Traceability System
PATS is a relational database project for AD350 that models the complete lifecycle and traceability of propulsion components, including valves, kits, IFMs, PIFs, IPUs, and environmental testing through MQC and ISTC chambers.
